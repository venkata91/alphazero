Sub-project 2 — Connect 4

Scaled the framework to a 6×7 board with gravity, column-based moves, and horizontal symmetry. Used α-β minimax-depth-8 as the eval baseline. The framework code (MCTS, network, trainer) was reused unchanged — only the Game subclass changed.

Done

Sub-project 3 — Chess

Full 8×8 chess: AlphaZero's 8×8×73 = 4672 move encoding (queen-like + knight + underpromotion), 20-plane input, StockfishOpponent via UCI as the eval baseline, and parallel self-play with a central NN-server batching inference across worker processes.

Spec → Plan →
Done

Sub-project 3b — Supervised Pre-training + AZ Refinement

Cold-start AlphaZero on chess is wall-clock infeasible on consumer hardware (~13 days on M4 Pro). Bootstrap the network from 50k Stockfish-vs-Stockfish games via supervised pre-training, then refine with a short AlphaZero loop. ~15 hours total. New code: corpus generator, supervised trainer, pretrain CLI subcommand — framework primitives reused unchanged.
